# Quest Editor Demonstration

Unity 2023.1.22f1 project used to develop **Quest Editor** — a visual, graph-based quest editor and a runtime
system that executes the quests.

The package lives in [`Packages/com.vokazhira.quest-editor`](Packages/com.vokazhira.quest-editor):

- [Documentation (English)](Packages/com.vokazhira.quest-editor/README.md)
- [Документация (русский)](Packages/com.vokazhira.quest-editor/README.ru.md)
- [Changelog](Packages/com.vokazhira.quest-editor/CHANGELOG.md) · [License (MIT)](Packages/com.vokazhira.quest-editor/LICENSE.md)

Install it into another project from a Git URL (**Window → Package Manager → + → Add package from git URL…**):

```
https://github.com/vokazhira/QuestEditorDemonstration.git?path=/Packages/com.vokazhira.quest-editor
```
